# Portfolio agent instructions

This file is a thin discovery adapter for AI systems working across the JosephJMWalker-MBA GitHub portfolio.

Start with [AI_START_HERE.md](./AI_START_HERE.md) to route the task to the narrowest justified repository or branch. For cross-project claims, comparisons, consolidation proposals, prior-art audits, or portfolio-level judgments, then read [PORTFOLIO_ORIENTATION.md](./PORTFOLIO_ORIENTATION.md).

Then read the canonical README or authority file of every named project before deciding anything about that project.

Do not infer project identity from repository names, recurring vocabulary, old conversations, or one implementation component.

Shared terms such as `provenance`, `evidence`, `authority`, `canonical`, `append-only`, or `human review` do not establish a shared ontology, runtime, or merger target.

If canonical sources are absent or contradictory, return **insufficient orientation** rather than inventing a synthesis.

For the protocol behind durable cross-provider handoffs and AI onboarding, see the TRACE repository's `AI_ONBOARDING.md`.
